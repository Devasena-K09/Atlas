# Atlas

Atlas is a cloud observability and system monitoring platform built using FastAPI.

## Features

- System Metrics API
- System Information API
- Modular FastAPI Architecture
- Real-time CPU Monitoring
- Memory Usage Tracking
- Disk Usage Monitoring
